# EDA on Retail Sales Data

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a retail sales dataset to understand customer behaviour, product performance, and sales patterns.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Dataset inspection and data quality checks
- Descriptive statistics
- Customer age group analysis
- Gender distribution analysis
- Top 10 product analysis
- Revenue by product category
- Correlation analysis
- Seasonal sales analysis
- Additional customer behaviour visualization
- Business insights and recommendations

## Key Findings

The analysis identified important patterns in customer demographics, product performance, discounts, previous purchases, and seasonal sales.

## Business Recommendations

The project provides actionable recommendations based on the analysis to support inventory planning, customer targeting, loyalty strategies, and promotional decisions.
