Project Description

This project performs customer segmentation analysis on an online retail dataset to understand customer purchasing behaviour. RFM (Recency, Frequency, and Monetary) analysis is used to identify key customer characteristics, followed by K-Means clustering to group customers into distinct segments. The resulting segments are analysed to identify customer patterns and develop targeted marketing strategies.

Tools Used

Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook

Key Analysis
Data cleaning and preprocessing
RFM analysis
Customer behaviour analysis
Feature standardization using StandardScaler
Elbow Method for selecting the number of clusters
K-Means customer segmentation
Cluster visualization and profiling
Marketing recommendations for each customer segment
